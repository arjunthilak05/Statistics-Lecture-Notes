Vectors as Arrows (Direction + Magnitude)

In 2D, a vector can also be visualized as an arrow pointing from the origin (0,0) to a point. The arrow has two properties: direction (where it points) and magnitude (how long it is).

Each vector is an arrow from (0,0) to its coordinates.
a=[3,2] points right 3 and up 2. b=[1,4] is steep. c=[5,1] is mostly horizontal.

Magnitude (Length) of a Vector

How long is the arrow? That's the magnitude — calculated using the Pythagorean theorem!

Magnitude Formula
|v| = √(x² + y²)
For v = [3, 4]: |v| = √(9 + 16) = √25 = 5
import numpy as np v = np.array([3, 4]) # Calculate magnitude magnitude = np.linalg.norm(v) print("Vector:", v) print("Magnitude:", magnitude) # Works for any dimension! v3d = np.array([1, 2, 3]) print("3D magnitude:", np.linalg.norm(v3d)) # √(1+4+9) = √14 ≈ 3.74
Vector: [3 4] Magnitude: 5.0 3D magnitude: 3.7416573867739413
📐 Pythagorean Theorem! Remember a² + b² = c²? The magnitude formula is the same thing! For a [3,4] vector, draw a right triangle — the arrow is the hypotenuse: √(3²+4²) = √25 = 5.

Dot Product — How Similar Are Two Vectors?

The dot product is the most important vector operation for AI! It multiplies matching elements and adds the results. It tells you how similar two vectors are.

Dot Product
a · b = a₁b₁ + a₂b₂ + a₃b₃ + ...
Multiply each pair, then add everything up!
Worked Example
a = [1, 2, 3]
b = [4, 5, 6]

a · b = (1×4) + (2×5) + (3×6)
     = 4 + 10 + 18
     = 32
import numpy as np a = np.array([1, 2, 3]) b = np.array([4, 5, 6]) # Dot product — 3 ways! print(np.dot(a, b)) # 32 print(a @ b) # 32 (@ operator!) print(sum(a * b)) # 32 (manual way)

Matrix Multiplication — The Big One!

Matrix multiplication is NOT element-by-element! It's a specific pattern of dot products between rows of the first matrix and columns of the second.

The Rule: Row × Column = One Number
Each cell in the result = dot product of a row from A and a column from B
Step-by-Step Example
A = [[1, 2],     B = [[5, 6],      [3, 4]]         [7, 8]] Result[0,0] = Row 0 of A · Col 0 of B = 1×5 + 2×7 = 5+14 = 19 Result[0,1] = Row 0 of A · Col 1 of B = 1×6 + 2×8 = 6+16 = 22 Result[1,0] = Row 1 of A · Col 0 of B = 3×5 + 4×7 = 15+28 = 43 Result[1,1] = Row 1 of A · Col 1 of B = 3×6 + 4×8 = 18+32 = 50 Result = [[19, 22],          [43, 50]]
A = np.array([[1, 2], [3, 4]]) B = np.array([[5, 6], [7, 8]]) # Matrix multiplication (NOT A * B, which is element-wise!) result = A @ B # Using @ operator # or: result = np.matmul(A, B) # or: result = np.dot(A, B) print("A @ B =") print(result)
A @ B = [[19 22] [43 50]]

The Shape Rule for Matrix Multiplication

You can only multiply matrices if the columns of A = rows of B. The result shape is rows of A × columns of B.

Shape Rule
(m × n) @ (n × p) = (m × p)
The inner dimensions must match! The outer dimensions give the result shape.
✅ Works!
(2×3) @ (3×4) = (2×4)
Inner 3s match ✓
❌ Error!
(2×3) @ (4×5)
3 ≠ 4 — can't multiply!
⚠️ A × B ≠ B × A! Unlike regular numbers, matrix multiplication is NOT commutative. The order matters! Always check your shapes.
