🎬 Part 1 — Netflix Uses Dot Products

How Does Netflix Know What You'll Like?

Every movie on Netflix is secretly stored as a vector of numbers. Each number represents how much of a certain quality the movie has.

Movie → Vector
Action score
0.9 ← lots of action
Comedy score
0.1 ← not very funny
Romance score
0.0 ← zero romance
Suspense score
0.7 ← quite suspenseful
Movie Vector = [0.9, 0.1, 0.0, 0.7]

And you are also stored as a vector — based on what you've watched and liked!

Your Taste Vector = [0.8, 0.2, 0.1, 0.6]

To find how well a movie matches you, Netflix does a dot product:

Match Score = 0.9×0.8 + 0.1×0.2 + 0.0×0.1 + 0.7×0.6
= 0.72 + 0.02 + 0.00 + 0.42
= 1.16 ← High! Netflix recommends it. ✅
🎬 The dot product IS the recommendation algorithm. Netflix does this for every movie in their library and shows you the ones with the highest scores!

📸 Part 2 — Images Are Matrices

A Photo is Just a Grid of Numbers

When your phone saves a photo, it doesn't save colors — it saves numbers. Each pixel is a number from 0 (black) to 255 (white). The whole image is a matrix!

The "Image" Grid
Stored as Matrix

📸 Real camera math: A 12-megapixel photo = 4000 × 3000 matrix. A color photo = THREE matrices (one each for Red, Green, Blue). AI image models like DALL·E read these matrices and learn from them!

Image Blurring = Matrix Operation (Convolution)

When Instagram applies a blur filter, it's doing a matrix operation called convolution. It slides a small "blur matrix" (called a kernel) across the image matrix.

🗣️ Part 3 — ChatGPT Turns Words into Vectors

Words Are Secretly Vectors Too

ChatGPT can't read words. It reads numbers. So every word is converted into a vector of numbers — called a word embedding. Similar words get similar vectors!

Word → Vector (simplified)
king
[0.9, 0.1, 0.8, 0.2] ← royalty↑ male↑
queen
[0.9, 0.9, 0.8, 0.2] ← royalty↑ female↑
dog
[0.1, 0.4, 0.1, 0.9] ← royalty↓ animal↑
cat
[0.1, 0.5, 0.1, 0.85] ← very similar to dog!

Now the magic: word math with vectors!

king - man + woman ≈ queen
Subtract the "male" direction, add the "female" direction → land on queen!
🧠 This is how ChatGPT knows that "Paris is to France as Tokyo is to ___" = Japan. It's just vector arithmetic!

🧠 Part 4 — Neural Networks = Matrix Multiplication

What IS a Neural Network Really?

People think neural networks are magic. They're not. A neural network layer is literally one matrix multiplication followed by a simple function.

The Whole Formula
output = ReLU( input @ weights + bias )
That's it. The entire "intelligence" of a layer in one line.
📊
input
Your data as a vector. For an image: all the pixel numbers flattened into one long vector.
⚖️
weights (a matrix!)
Numbers the network learned during training. This is where all the "knowledge" lives. When you train an AI, you're just updating these numbers.
⚡
ReLU (activation function)
Just max(0, x) — if the number is negative, make it 0. This tiny step is what lets the network learn non-linear patterns!

GPT / ChatGPT — Billions of These Operations

ChatGPT has 175 billion weights stored as matrices. When you type a message:

1
Your words → turned into a matrix of vectors (word embeddings stacked up)
2
That matrix flows through 96 layers of matrix multiplications (GPT-3)
3
Each layer does: input @ weight_matrix + bias then ReLU
4
The final output matrix is converted back to words → that's the reply you see!
🚀 Training an AI = finding the right weight matrices. You start with random matrices, check how wrong the output is, then slightly adjust every number in every matrix. Repeat millions of times. That's machine learning!
🌍 Part 5 — Real AI Systems You Use Daily

Every App You Use Runs This Math

📱
Face Unlock on Your Phone
Your face photo → pixel matrix → matrix multiply through neural network → output vector compared with stored face vector via dot product. If similarity is high enough → unlocked!
🎵
Spotify "Discover Weekly"
Each song → vector (energy, tempo, mood...). Your taste → vector. Every Monday, Spotify computes dot products of your taste vector against all 80 million songs and picks the top matches.
🔍
Google Search
Your search query → vector. Every webpage → vector. Google takes the dot product of your query vector with every page and returns the highest scores. That's why "fast running shoes" finds "quick sneakers" — similar vectors!
🚗
Self-Driving Cars
Camera frames → pixel matrices → 100+ neural network layers (all matrix multiplications) → output vectors telling the car: pedestrian at [x,y], car at [x,y], turn left 5°. All in 50ms!
